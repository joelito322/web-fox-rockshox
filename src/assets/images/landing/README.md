Fotografías reales descargadas del CDN enlazado por sus páginas originales; variantes locales WebP a 720 px para móvil y 1280 px para retratos / 1600 px para el salto horizontal, calidad 65. No hay hotlink en la visita ni generación con IA. Los autores y enlaces se conservan discretamente en la portada.

Las tres páginas identifican sus fotos como gratuitas bajo Unsplash License. La etiqueta automática de la página de Leysin menciona motocross; se inspeccionó visualmente la imagen y muestra una bicicleta MTB sin motor. La aplicación describe el contenido observado, no replica esa etiqueta incorrecta.

Son ambientación del producto: no afirman colaboración con marcas visibles, un modelo comercial exacto ni un montaje creado por ATLAS. Se ajustan encuadres responsive sin incorporar las marcas de terceros a la identidad ATLAS. El recorte conserva ciclista/terreno; la vista aérea aporta recorrido y escala.

CDN de procedencia en `images.unsplash.com`: `photo-1627406312635-ddd4fd9ad13a`, `photo-1633077545666-a642866e812a`, `photo-1680508128888-505d636574ff`. Las transformaciones de formato/tamaño las entrega ese servicio. Sustituir imágenes exige registrar autor/fuente.

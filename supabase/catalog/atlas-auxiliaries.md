# Auxiliares ATLAS v1

Diseño propio para la representación visual del configurador. No son productos comerciales ni referencias de una marca de componentes; no tienen SKU, precio o disponibilidad comercial. Las dimensiones de esta tabla pertenecen al diseño visual, sin atribuirlas a un fabricante.

| Pieza | Dimensiones del diseño |
| --- | --- |
| Manillar | 780 mm de anchura; abrazadera 31,8 mm; elevación 25 mm |
| Potencia convencional | Abrazadera de dirección 28,6 mm; manillar 31,8 mm; longitud 40 mm; ángulo 0° |
| Sillín | 260 × 145 mm; dos raíles de referencia |
| Tija fija | Diámetro 34,9 mm; longitud 350 mm; inserción visual 200 mm |

Se conservan bajo marca ATLAS, representación genérica y recurso `atlas-bike-v1`. Admiten color personalizado. La procedencia se registra en `visual_assets.reference_notes` con la ruta de este archivo; `sources` no inventa un sitio web para una fuente local. Si se cambian medidas o recurso después de publicar, crear una variante/recurso con nueva identidad.

La potencia directa DH se define a continuación como recurso independiente; la convencional no se presenta como equivalente.
